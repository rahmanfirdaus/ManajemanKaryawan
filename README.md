# Manajemen Karyawan
# 🧾 Aplikasi Manajemen Karyawan | Employee Management App

Desktop app berbasis C# Windows Forms untuk mengelola data karyawan menggunakan database MySQL.

C# Windows Forms-based desktop application for managing employee data using a MySQL database.

---

## 📦 Fitur Utama | Main Features

- ➕ Tambah, ✏️ Edit, ❌ Hapus data karyawan
- 🔎 Pencarian & filter data / Search & filter functionality
- 📋 Form tampilan data terpisah / Separate data viewing form
- 🔄 Tombol Reset & Kembali / Reset & Back button
- 📊 Tampilan tabel modern (DataGridView rapi & otomatis) / Modern DataGridView layout

---

## 💻 Teknologi | Technology

- ✅ C# (.NET Windows Forms)
- ✅ MySQL Database
- ✅ MySQL.Data Connector (NuGet)
- ✅ Git & GitHub
